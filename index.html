Base Mecánica

Chasis Modular
Estructura ensamblada con el kit ExploraRobótica. Rígida y ligera. La misma base soporta 3 configuraciones distintas.
⚙️
2 Motores DC
Tracción diferencial: cada motor controla un lado de forma independiente. Distintas velocidades = giro controlado.
🛞
4 Ruedas
2 ruedas motrices + 2 ruedas libres de apoyo. Sistema diferencial que permite girar sin necesidad de dirección.
🔄
Tracción Diferencial
Adelante: ambos motores igual velocidad  ·  Giro: un motor más rápido  ·  Pivote: motores opuestos.
🦾
Efector Intercambiable
La misma base soporta: pinza robótica · sistema levantacargas · sensor ultrasónico.
Los 3 Robots
03/06
Tres Misiones — Una Base
Robot 01
🦾 Pinza Robótica
Control remoto IR para mando manual. Servomotor 9g abre y cierra la pinza con precisión. Modo autónomo: recorre trayectoria en L transportando objetos de extremo a extremo de forma repetida.
📱 Control IR🤖 Autónomo
Robot 02
🏗 Levantacargas
Sistema de cuerda, polea y horquilla accionado por servomotor. Levanta y baja cargas automáticamente. Opera en bucle autónomo por la trayectoria en L cargando y descargando objetos.
🤖 100% Autónomo
Robot 03
📡 Evasor de Obstáculos
Sensor ultrasónico HC-SR04 mide distancias en tiempo real. Navega laberintos de cartón sin chocar: detecta obstáculo → retrocede → evalúa derecha e izquierda → elige el camino libre.
📡 HC-SR04🤖 Autónomo
Sistema Electrónico
04/06
Circuito Electrónico
PILAS
6 pilas AA en serie → 9V. Alimentan el Arduino por el jack barrel. Los motores también toman corriente directamente desde aquí.
ARDUINO
El cerebro. Ejecuta el código a 16MHz. Lee sensores, calcula distancias, decide movimientos y controla todos los actuadores.
L293D
Puente H integrado. Amplifica la señal del Arduino (5V → potencia completa). Controla la dirección y velocidad (PWM) de 2 motores DC.
HC-SR04
Emite 8 pulsos ultrasónicos a 40kHz, mide el tiempo de rebote. Fórmula: distancia = tiempo × 0.0343 / 2. Rango: 2cm – 400cm.
SERVO 9G
Motor de posición controlada por señal PWM. Gira exactamente de 0° a 180°. Acciona la pinza o el sistema de poleas del levantacargas.

void setup() {
  pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT);
  detener();  // motores apagados
  delay(1500); // pausa inicial
}
long dist = medirDistancia();
// Pulso 10µs → pulseIn → tiempo (µs)
// dist = duracion × 0.0343 / 2 (cm)
if (dist < 12) { // ¡Obstáculo!
  maniobra();
} else if (dist < 20) {
  setMotores(1,1,115); // precaución
}
setMotores(-1,-1,155); // reversa
delay(480);
frenar(); // freno suave
setMotores(1,-1,150); // gira der
delay(T_GIRO_90);
long dDer = medirDistancia();
if(dDer > 30) return; // libre!
acelerar(1, 1, VEL_LIBRE);
// Rampa suave: 75→175 en ~200ms
// ↺ loop() → medir de nuevo...
